# Hollow Knight MidAirHealing Mod

Allows you to heal in mid-air (as well as on water).

### Requirements
- Hollow Knight v.1.5.78.11833
- Any mod manager with included [HK Modding API](https://github.com/hk-modding/api) (like [Scarab](https://github.com/fifty-six/Scarab) or [Lumafly](https://github.com/themulhima/lumafly))

### Installation
1. Download the latest [release](https://github.com/user500050/HKMidAirHealing/releases)
2. Extract the archive to the following directory:
    * `[Game Install Directory]/hollow_knight_Data/Managed/Mods/`
3. If the `Mods` folder doesn't exist, create one
